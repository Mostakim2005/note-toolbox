What it is for

The short version a new maintainer needs before touching code.

Find any asset fast

Filter images, video, audio and documents by folder, extension, usage, or typed text in a modal that never loses its action bar.

See the whole picture

Grid tiles and the Quick Look lightbox letterbox instead of cropping, so diagrams and tall screenshots remain readable.

Clean up safely

Rename with tokens, move, and trash many files at once with collision guards, per-file error isolation and link-preserving file-manager calls.

Build forms inline

?[status] becomes a live select bound to frontmatter; ?[status|Done] is a self-contained inline select.

Reuse everywhere

Other plugins call openImagePicker, pickFile, or pickAsset and get the same visual browser.

Insert where you work

Drop embeds into notes, add file nodes to Canvas, or place images and embeds into Excalidraw with a floating overlay button.

Decisions worth knowing

Each one replaced a working-looking approach that failed at scale.

Chosen

TTL link cache

Recompute at most every 4 seconds, plus explicit invalidation on metadata, rename, and delete.

Chosen

O(1) selection

Resolve selected paths with getAbstractFileByPath; never scan the vault on click or drag.

Chosen

Atomic frontmatter

processFrontMatter writes dropdown properties; regex YAML editing is banned.

Chosen

Bounded decoding

Images, video, and audio race a 1500 ms timeout so corrupt files cannot hang promises.

Chosen

Fragment batches

Build 50 cards/fixtures off-DOM, append once, and skip off-screen paint with content-visibility.

Chosen

File-manager mutations

renameFile and trashFile preserve backlinks and vault trash semantics.

Landmines

If a future change touches these areas, read docs/DECISIONS_AND_TRAPS.md first.

Trap

Alias re-registration

Editing aliases re-adds command IDs; removed aliases can linger until reload.

Trap

data.json keys

Renaming a settings key without migration silently discards user configuration.

Trap

nt-* classes

Every class is a contract between CSS and createEl({ cls }); rename both sides together.

Trap

runtime/ drift

The frozen bundle is a fallback, not a mirror of the live vault or of src/.

Trap

Async listeners

Wrap with voidAsync; otherwise lint fails and rejections escape.

Trap

Cache invalidation

Clear both the link cache and dimension cache on rename/delete, or orphans and sizes go stale.
